# 欧洲分支（其他境外目的地同样适用）

目的地在欧洲或其他境外地区时读本文；非欧洲目的地按同样思路处理，签证/交通规则逐项重新核实。通用流程、内容口径、当地美食推荐见 SKILL.md；实时数据见 `live-data.md`，附带脚本见 `scripts.md`。

## 工具链

- **Google Maps 工具（优先）**：见下方“Google Maps 接入”。已连接时，自驾里程时长、城内步行/公交时长、地点坐标都用它实测；未连接时按下面各条用 WebSearch/WebFetch，并在页面标注“参考”。
- **交通**：WebSearch/WebFetch 查运营商官网或 Trainline/Omio 的车次时长、是否强制订座（TGV、Frecciarossa、Eurostar、AVE 等）、夜车；火车以运营商官网为准，Google 公交路线只作交叉核对。
- **天气**：出发 ≤10 天用预报（Google Maps 工具有天气时优先用），否则同期气候均值；加写**日出日落**（北欧冬季下午 3–4 点天黑）。
- **门票**：官网核实价格、开放预约规则并**算出具体开售日期**（见校验规则 4）、闭馆日、免费日；标注查询日期。
- **节假日/罢工/节庆**：目的国公共假日（复活节、圣灵降临节、8 月意法本地人休假、圣诞新年闭馆）、周日商店关门（德奥等）、已公告罢工（sciopero / grève / Streik）、**节庆当年确切日期**（狂欢节、圣诞集市等常随复活节或固定周末浮动），和逐日路线对齐（规则见 SKILL.md 第 2 步）。
- **城市准入费/新收费**：如威尼斯进城费（指定日期白天进城需提前登记缴费；住在市内免缴，但也要申请豁免码）、罗马特雷维喷泉池边区收费等；日期、时段、金额和豁免规则每年公布，查当年官方规则，写进当天贴士与预算。
- **汇率**：查当日 EUR/CNY 等，页面注明日期。
- **地图**：每天一个 Google Maps 路线链接（https）：
  `https://www.google.com/maps/dir/?api=1&origin=A&destination=B&waypoints=C|D&travelmode=walking|transit|driving`
  - 地名用英文/当地语 + 城市名并 URL 编码。
  - **途经点按手机算**：未装 Google 地图 App 时手机浏览器最多只认 3 个，App 和电脑最多 9 个；每条链接 ≤ 3 个途经点，多了拆成两条。
  - **公共交通（transit）不支持途经点**：Google 地图的多目的地路线不含公共交通，带 waypoints 的 transit 链接会丢掉中间站。火车/公交段一段一条链接，只写 origin → destination。
  - 另附全程城市间总览链接：多城串联用 driving + waypoints 展示城市顺序，只作地理示意（火车行程在按钮文字或说明里注明），班次仍以运营商为准。

## Google Maps 接入

与国内高德同一原则：**里程、时长、坐标必须实测，不凭记忆**。

1. **找工具**：开工前用 ToolSearch 搜 `google maps` / `directions` / `routes` / `places` / `geocode`，按返回的**真实 schema** 调用，禁止凭记忆构造参数。常见的 Google Maps MCP 提供：地点检索/地理编码、路线规划（driving / walking / transit）、距离矩阵，部分还有天气；以实际搜到的为准。
2. **没有工具时**：告诉用户可在 claude.ai 连接器中添加 Google Maps（或自建 Google Maps MCP，需要 Google Maps Platform API Key 并开通 Places、Routes/Directions、Geocoding 等 API，密钥由用户自己保管，不要写进路书或仓库）。用户选择不接入时继续规划：自驾/步行时长改用可追溯来源，页面标注“参考，未实测”，不得用直线距离充数。
3. **标准顺序**（已接入时）：
   1. **列节点**：按日列出住宿、景点、车站/机场。
   2. **取坐标/地点**：每个节点做地点检索或地理编码，用英文/当地语名称 + 城市 + 国家，避免重名（Paris, France vs Paris, Texas）；记下标准名称与坐标。
   3. **逐段实测**：自驾段用 driving，城内用 walking/transit；写成 `"285km · 约3.2h"` 或 `"步行 1.8km · 约25min"`。多段可并行或用距离矩阵一次取。
   4. **校验节奏**：每天把实测时长相加，对照下方“校验规则”（单日驾驶 ≤ 4–5 小时、步行量是否过大）。
   5. **生成链接**：用第 2 步的标准名称拼每日与总览的 `https://www.google.com/maps/dir/?api=1...` 链接（地名比坐标可读，重名风险高时用 `纬度,经度`），途经点与 transit 限制见上方“地图”。
4. **已知坑**：
   - 公交/火车时刻只是参考，班次、订座与罢工以运营商官网为准。
   - 自驾时长是理想路况，山路、夏季海滨、周五傍晚出城按 +20%~40% 估；ZTL、Crit'Air、Vignette 不会体现在路线里，另行核实。
   - 链接写进 HTML 时 `&` 转义为 `&amp;`；二维码编码路书网页链接，不编码地图链接。
   - **跳转 App**：`https://www.google.com/maps/dir/?api=1...` 是 Google 官方跨平台链接，手机已装 Google 地图 App 时直接在 App 打开（可一键开始导航），未装则打开网页版；不要改用 `comgooglemaps://` 等私有协议。页面上不加 Google 地图的打开说明、网络或离线地图提示。

## 校验规则

1. **节奏（最常见问题：城市太多）**
   - 每城至少 2 晚，大城（巴黎/罗马/伦敦/巴塞罗那）3–4 晚；城市数 ≤ 总天数 ÷ 2.5，超了给“砍城版”。
   - 换城日按损失半天算；抵达首日倒时差只安排轻松散步；回国前一晚住机场所在城市。
2. **路线形状**
   - 优先**开口程机票**（A 进 B 出），给出与同进同出的时长对比。
   - 城际 ≤ 4–5 小时优先火车；更远考虑廉航（注明行李费、远郊机场）或夜车。
   - “不想去 X 地”同样区分“可中转”与“完全避开”，两案时长都给用户。
3. **签证与入境（中国护照重点）**
   - 申根向停留最长的国家申请，天数相同向首入国；路书须与签证行程单一致，改线路要提醒是否影响主申请国。
   - **用户问“哪国好签”**：说明主申请国由行程决定、不能自由选；专挑实际待得少的国家递签属于“签证购物”，有拒签、入境被质疑、签证被撤销的风险。真正影响过签的是材料一致性、资金与工作证明、出行记录、递签时机。没有可靠的分国籍数据时不给“好签排名”。
   - **递签窗口**：最早出发前 6 个月、最晚前 15 天；春节、暑假前签证中心拥挤，提醒尽早约号。
   - 90/180 天规则；英国、爱尔兰需单独签证；瑞士是申根非欧盟（CHF、漫游另计）；巴尔干逐国核实。
   - EES 首次入境录指纹面部，预留排队时间；ETIAS 仅针对免签护照，政策以出发前官网为准。
   - 用户需要时额外输出“签证行程单”（日期/城市/住宿/交通）。
4. **预约窗口**（比门票价格更重要）：热门项目多为限流、实名/定时入场、提前开售且易售罄（卢浮宫、梵蒂冈博物馆、斗兽场、《最后的晚餐》、圣家堂、阿尔罕布拉宫、新天鹅堡、安妮之家、埃菲尔铁塔登顶、少女峰等）。
   - 规划阶段按官网规则**算出具体开售日期**：滚动放票的，参观日往前推窗口天数（如梵蒂冈博物馆约提前 60 天、斗兽场约提前 30 天且实名，以官网当期规则为准）；按批次/季度放票的（如《最后的晚餐》），查官网公布的放票日。
   - 写成“2026-03-15 周日 09:00（当地）· 北京时间 16:00”，换算时注意夏令时；放进页面置顶的“抢票日历”，交付时按开售日期排序提醒。
   - 闭馆日（多为周一/周二；梵蒂冈博物馆周日闭馆，每月最后一个周日除外）与日程逐天比对。
5. **自驾**
   - 中国驾照在各国认可方式差异大，**逐国并向租车公司核实**，不给笼统结论。
   - 必查：意大利 ZTL 限行区、法国 Crit'Air、奥地利/瑞士/捷克等 Vignette、跨境异地还车费、自动挡需提前订、大城停车难。
   - 单日驾驶 ≤ 4–5 小时，山路（阿尔卑斯、多洛米蒂）按时间而非公里算。
6. **季节**：夏季南欧高温与人潮、8 月本地店歇业；冬季日照短、山区海岛设施关闭、圣诞集市季、12/25 与 1/1 大量闭馆。

## 页面模块

1. 封面：标题、日期、国家城市串、总天数、节奏摘要、关键标签（主申请国、日落时间、节庆冲突）
2. **航班**（有机票时）：航班表 + 转机/变动/出门时间提醒（见 `iteration.md`）
3. **抢票日历**（置顶）：开售日期（当地 + 北京时间）· 项目 · 规则 · 官网链接，按开售日期排序
4. **出行提醒**（实时数据）：罢工、恶劣天气预警、景点临时关闭
5. **签证与入境清单**：主申请国及原因、递签窗口、EES、材料、申根医疗险保额≥3 万欧元
6. **行程总览**：城市间 Google Maps 链接 + 城际交通表（日期 · 车次/航班 · 时长 · 是否订座 · 订票平台 · 参考价）
7. 天气与日照（预报/气候均值标记 + 更新时间，实时数据）
8. **住宿**：首选/备选 · 起价 · 理由；城市税、入住截止、寄存、免费取消
9. 逐日路书时间轴：城市 · 住宿区域 · 当日地图链接 · 上午/下午/晚上 · 景点 · 具体美食店 · 门票 · 贴士（闭馆日、步行量、防盗热点、进城费）
10. **当地美食推荐**：按城市分组，代表菜 + 推荐店（评分来源 · 价位 · 营业时间与休息日 · 是否预约 · Google 地图导航按钮）
11. 门票与预算：住宿/城际交通/市内交通/门票/餐饮分项，外币 + 人民币（**汇率为实时数据**，显示更新日期），城市税、进城费单列
12. 穿着建议（教堂遮肩膝、石板路步行鞋、雨具、山区保暖）
13. 拍摄与记录设备（用户要求时，见 `iteration.md`）
14. 实用信息：插头（多数 C/F，英国 G，瑞士 J，意大利 L）、时差、小费、退税、eSIM、支付习惯
15. 安全与应急：扒窃高发区与手法、欧盟急救 112、外交部全球领保热线 +86-10-12308、护照丢失处置
16. 页脚：数据来源与查询日期

签证、驾照、入境政策只给“需核实要点 + 官方入口”，不下法律结论。
